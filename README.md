# PharmaCare+ Final Multi-Hospital Prototype

## Open in VS Code
1. Extract the ZIP.
2. Open Visual Studio Code.
3. Choose **File → Open Folder**.
4. Select `PharmaCarePlus_Final_MultiHospital`.
5. Open `index.html`.
6. Install the **Live Server** extension if needed.
7. Right-click `index.html` and choose **Open with Live Server**.
